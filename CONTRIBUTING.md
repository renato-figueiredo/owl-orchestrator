# Contributing

- One focused change per PR; tests and typecheck must pass.
- Read `CLAUDE.md` (golden rules) and `docs/01-product/rules-and-compliance.md` first.

## Provenance policy
We do not accept contributions copied, translated or derived from the leaked Claude Code source code
or any other proprietary code (including proprietary web bundles). PRs in that situation will be closed.
Reusing permissively licensed open-source code is fine when the license is respected and credited.
