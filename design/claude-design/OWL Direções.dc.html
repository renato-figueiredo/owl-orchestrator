Três jeitos de a coruja vigiar

Mesmos dados e tokens --c-* nas três. O que muda é o layout-assinatura, a tipografia e onde a aprovação mora. Escolha uma (ou misture: 1a, 1b, 1c) e eu expando para fundamentos, componentes e as 4 páginas.

1a

Observatório

Hanken Grotesk + JetBrains Mono
  1. Layout: faixa “Vigia” fixa no topo com toda run viva; trilho de ícones de 56px, sem lista lateral.
  2. Run: linha do tempo vertical à direita, com tempo em mono na margem, como um log de voo.
  3. Âmbar: só o contador de aprovações, o foco e o cursor. Rodando é creme com olhos piscando.
  4. Tipo: uma grotesca calma para ler, mono para tudo que é dado (ids, tempos, custos).
  5. Coruja: os olhos “••” viram o indicador de status de agente.

1b

Registro

Geist + Geist Mono
  1. Layout: sem sidebar. Uma barra de comando no topo (breadcrumb + seções + ⌘K) e uma coluna de log no centro.
  2. Run: as ferramentas entram no próprio transcript como linhas de log; a aprovação é um bloco que interrompe o fluxo.
  3. Âmbar: o prompt “›”, o marcador ▲ de portões e a faixa de aprovação. Nada mais.
  4. Tipo: mono domina (é um terminal que respira); a sans fica para texto corrido e títulos.
  5. Quadro: raias horizontais por status, ordenadas por urgência: o que espera você fica no topo.

1c

Mesa de decisão

Bricolage Grotesque + Instrument Sans + IBM Plex Mono
  1. Layout: a bandeja “Esperando você” fica sempre à direita. As aprovações são o painel fixo, e a run não.
  2. Run: uma régua horizontal de etapas sob cada resposta do agente; clicar numa etapa abre o detalhe logo abaixo.
  3. Quadro: agrupado por quem está com a bola: Agentes · Você · Feito.
  4. Tipo: uma display de traço angular (ecoa o “W”) só em títulos de tela; sans e mono no resto.
  5. Âmbar: a bandeja e a zona “Com você” têm moldura âmbar; o resto é noite e creme.
