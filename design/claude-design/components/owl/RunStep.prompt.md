Passo de uma run dentro de `<ol>`; desliza ao entrar, expande para mostrar entrada/saída.

```jsx
<ol style={{margin:0,padding:0}}>
  <RunStep time="00:03" name="Read" detail="src/adapters/ollama.ts" duration="0,2s" />
  <RunStep time="00:48" name="Bash" detail="pnpm test adapters" duration="24s…" status="running" last />
</ol>
```
