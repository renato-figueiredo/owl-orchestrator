# Screenshots

Put screenshots of the app here (PNG, ~1280 px wide, no personal data: use a throwaway project and the fake/neutral
prompts). Suggested names, one light and one dark when it makes sense:

| File | Shows |
|---|---|
| `chat-light.png` / `chat-dark.png` | A conversation with a streamed answer and the run panel |
| `improve-prompt.png` | The refined prompt waiting for review (edit / run / improve again / discard) |
| `projects.png` | The sidebar with projects and conversations |

Reference them from the READMEs with a relative path, e.g. `![Chat](docs/images/chat-dark.png)`, and add alt text.
Keep each file under ~300 KB. Screenshots go stale quickly while the UI is changing: re-capture them before a release.
